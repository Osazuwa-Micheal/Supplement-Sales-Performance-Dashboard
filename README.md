# Supplement-Sales-Performance-Dashboard

This project presents a *Power BI dashboard* built to analyze and visualize supplement sales data.  
The dashboard provides *actionable insights* into revenue, sales performance, product categories, and market trends — helping stakeholders make *data-driven decisions*.  

---

##  Features  
- *Total Revenue:* $22.91M  
- *Total Units Sold:* 658K  
- *Average Price:* $34.78  
- *Growth Metrics:*  
  - Year-over-Year (YoY) Growth: *+23.81%*  
  - Month-over-Month (MoM) Growth: *+1.67%*  
- *Top Performing Product:* *Biotin* (Vitamin category)  

---

##  Key Insights  
- *Sales by Platform:* Breakdown across *iHerb, Amazon, and Walmart*.  
- *Revenue by Category:* Vitamins lead with *$4.30M*, followed by Minerals and Performance products.  
- *Top-Selling Products:* Biotin, Ashwagandha, and Fish Oil.  
- *Returns Analysis:* Only *1% of units sold were returned*, showing strong customer retention.  
- *Revenue Trend:* 12-month revenue analysis showing seasonality and growth patterns.  

---

## Purpose  
This dashboard is designed for:  
- Tracking *business KPIs* at a glance.  
- Identifying *top-performing products and categories*.  
- Monitoring *sales platform performance*.  
- Supporting *strategic decision-making* with data insights.  

---

##  Tools Used  
- *Power BI* → Data visualization  
- *DAX* → Time intelligence & calculations  
- *Data Modeling* → For performance optimization
